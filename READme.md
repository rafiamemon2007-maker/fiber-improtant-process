
# TextilePro AI

A Streamlit web application for Textile Engineering students.

## Features
- Fibre Knowledge Center
- Textile Manufacturing Processes
- Ne to Tex conversion
- Tex to Ne conversion
- Tex to Denier conversion
- Denier to Tex conversion
- Yarn mass calculation
- Fabric GSM calculator
- Textile quiz
- Textile glossary

## Installation

Install Python 3.10 or newer.

```bash
pip install -r requirements.txt
```

## Run the application

```bash
streamlit run app.py
```

## Deployment

1. Upload app.py, requirements.txt and README.md to GitHub.
2. Open https://share.streamlit.io/
3. Connect your GitHub repository.
4. Select app.py as the main file.
5. Click Deploy.

## Important

This is an educational application, not an industrial
process-control system.
